## Core Security Concepts

*[ATTACK SURFACE]: The total set of ways an attacker can interact with your systems.
*[BLAST RADIUS]: The maximum scope of damage from a single compromise.
*[CIA TRIAD]: Confidentiality, integrity, and availability goals for protecting systems.
*[COMPENSATING CONTROL]: A safeguard that reduces risk when ideal controls are not yet possible.
*[CROWN JEWEL ASSET]: A system or dataset with high business impact if compromised.
*[DEFENSE IN DEPTH]: Layered controls that reduce single-point security failure.
*[EXPLOITABILITY]: The realistic chance a weakness can be abused in context.
*[THREAT MODEL]: A structured analysis of likely threats, assets, and abuse paths.

## Vulnerability and Testing Terms

*[CVE]: Common Vulnerabilities and Exposures identifier for known vulnerabilities.
*[CWE]: Common Weakness Enumeration category describing software weakness classes.
*[DAST]: Dynamic application security testing against a running application.
*[SAST]: Static application security testing against source code or bytecode.
*[IAST]: Interactive application security testing during runtime with instrumentation.
*[PENTEST]: Manual or assisted offensive testing to validate real attack paths.
*[RED TEAM]: A group simulating realistic adversary behavior to test defenses.
*[FALSE POSITIVE]: A finding that appears vulnerable but is not exploitable.
*[FALSE NEGATIVE]: A missed vulnerability that should have been detected.

## Identity and Access

*[IAM]: Identity and access management policies and permission systems.
*[WIF]: Workload Identity Federation for keyless external workload authentication to GCP.
*[MFA]: Multi-factor authentication requiring more than one verification factor.
*[RBAC]: Role-based access control where permissions are assigned by role.
*[ABAC]: Attribute-based access control using user, resource, and context attributes.
*[JIT ACCESS]: Just-in-time short-lived privileged access for specific tasks.
*[PAM]: Privileged access management for high-risk credential controls.

## Cloud and Platform Security

*[CSPM]: Cloud security posture management for misconfiguration detection.
*[CWPP]: Cloud workload protection platform for host and container runtime security.
*[K8S]: Kubernetes shorthand used in engineering and operations.
*[NAMESPACE]: A Kubernetes isolation boundary for groups of resources.
*[NETWORK POLICY]: Kubernetes policy controlling allowed pod-to-pod traffic.
*[SERVICE ACCOUNT]: A Kubernetes identity used by workloads.
*[GCP]: Google Cloud Platform.
*[GKE]: Google Kubernetes Engine.
*[GCS]: Google Cloud Storage.
*[SCC]: Security Command Center for cloud risk and posture findings.
*[CMEK]: Customer-managed encryption keys in Cloud KMS.
*[VPC SC]: VPC Service Controls for data exfiltration protection.
*[SBOM]: Software bill of materials listing application components and dependencies.

## Operations and Governance

*[GRC]: Governance, risk, and compliance processes for security programs.
*[IR]: Incident response process for detecting, containing, and recovering from incidents.
*[MTTD]: Mean time to detect a security issue.
*[MTTR]: Mean time to remediate a verified security issue.
*[RISK REGISTER]: A tracked list of risks, owners, mitigations, and status.
*[SLA]: Service level agreement that defines expected service commitments.
*[SLO]: Service level objective target used to measure reliability.
*[SOAR]: Security orchestration, automation, and response workflows.
*[SIEM]: Security information and event management for centralized event analysis.
*[TABLETOP EXERCISE]: A scenario-based walkthrough used to test incident readiness.
